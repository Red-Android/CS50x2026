# 🏎️ Project: The Ignition

Project: The Ignition A CS50x 2026 Week 0 Showcase
This project is a showcase of the concepts that the WEEK 0 of CS50x2026 taught

🛠️ Core Systems and Features:
    For the control system, i used the basic function block which scratch provides basic motion using the Motion block palette.
    
📡 On Board Live telemetry System:
    I did not just keep the score the same all the time. I made it so that it changes in time so you can see how long you have been driving.

🚦 The Dual Directional Traffic:
    I made the traffic go both ways. The other cars move on their own in directions. This section of one of the toughest and time taking part of the whole project. And the biggest learning point of the whole project.

⚡ The Speed:
    Initially though of implementing a velocity function, but was unable to do so, so i stayed on a simpler approch towards the Speed of all the NPC vehicles which are controlled by a single user defined input.

💥 The Collison system:
    Its not a autobahn where you just drive and drive, gonna watch the roads or the game will end way quickly that you thought.
    The Collison System has sound as well as visual effect and its connected to the health system of of the controlled sprite

🛡️ Health System:
    Gonna watch your health otherwise game's over, apart from that, the health system detects whether you had a collison with a npc or not, and if you have, a invinciblity frame is also there to avoid the sudden game over, taken this idea from a car game in the scratch.mit.edu studio site.

👁️ The Sensors:
    Placed physical sprite to work as sensor for the npc cars.

# 🔧 Final Version Changes
---------------------------
1. I had to make some changes to the game to make it work well.

2. I took out the fuel: I did not want the game to be about running out of fuel I wanted it to be about driving and surviving.

3. I changed the score: I made it so that the score changes in time so you can see how well you are doing.

4. I made the controls easier: I made it so that all the other cars are connected to one thing that controls how fast they go. This makes it easy to change how hard the game is.

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

# 🚧 Challenges I Faced
------------------------
1. Making this game was hard. I had to solve a lot of problems.

2. The car would move back to the start: sometimes the car would go back to the beginning of the game and I did not want that to happen.

3. The speed was too complicated: I was going to make the speed really complicated. Then I realized it was not necessary.

4. The other cars would get confused: the traffic system was not working right so I had to fix it.

5. The sensors were hard to place: it was hard to get the helpers, in the right spot.

6. The crashes were messy: the system that handled the crashes was not working right so I had to start over.

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

# 🎯 How to Play
-----------------
Choose how hard you want the game to be: you can pick how you want to go at the start.

Drive the car: use the arrow keys to move the car.

Try to survive: if you get hurt much the game is over.
